# Example plugins

| Folder | Shows |
|---|---|
| `word-count` | A workflow node with routing and plugin configuration |
| `clock-panel` | A workspace panel with saved state |
| `slugify-tool` | A tool, delivered as a node |
| `openai-preset` | A model provider preset, with no code |

Install one from the Plugins panel by pasting its full folder path. The SDK reference is in
[docs/PLUGIN_SYSTEM.md](../../docs/PLUGIN_SYSTEM.md).
